# Rock Paper Scissors

A simple Python console implementation of the classic Rock, Paper, Scissors game.

## Features

* Play against a computer opponent
* Random bot choices
* Countdown before each round
* Personalized player name
* Clear win/lose/draw results

## Requirements

* Python 3.10 or newer (uses `match` statements)

## How to Run

```bash
python main.py
```

Enter your name, choose one of the available options, and the game will determine the winner.

## Example

```text
Welcome to Rock paper scissors!
Your name: Alex

Enter your hand sign
1 - Rock
2 - Paper
3 - Scissors
Your choice: 2

[Referee]: 3...
[Referee]: 2...
[Referee]: 1...
[Referee]: GO!

[Alex]: I choose Paper!
[Bot]: I choose Rock!
The verdict is... Alex wins!
```
